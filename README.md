# 🛡️ Bankism: Real-Time Visual AI Firewall & Guardrail Defense

**Bankism** is a browser-based cybersecurity defense dashboard designed as a real-time proxy and security shield between banking customers and financial AI models. 

Built for the **PromptWars x UVCE** hackathon, this project features a multi-layer defense matrix that inspects, sanitizes, and blocks malicious prompts before they compromise banking LLMs or databases.

---

## 🚀 Winning Features & Architecture

* **Multi-Layer Defense Matrix:** Visualizes incoming prompts passing through 3 discrete security gates:
  1. **Layer 1: Sanitizer Gate** — Detects system prompt overrides, jailbreaks, and rule-bypass keywords.
  2. **Layer 2: PII Masking Shield** — Scans and auto-redacts sensitive financial identifiers (credit card numbers, PINs, SSNs) on the fly.
  3. **Layer 3: Intent & Sentiment Classifier** — Evaluates user tone and request classification.
* **Interactive Rule Toggle Engine:** Allows security auditors/judges to toggle specific firewall rules ON/OFF in real-time and observe how security behavior adapts.
* **Live Threat Score Meter:** Dynamic risk gauge assessing incoming traffic threat levels.
* **Audit Logs & Telemetry:** Real-time logging table tracking block/allow metrics, timestamps, and threat categories.
* **Pre-Built Attack Simulators:** Quick-test buttons to instantly trigger common banking AI threat vectors.
